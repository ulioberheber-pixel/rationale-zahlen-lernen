Rationale Zahlen – Erklärungen

Grundlagen, Beispiele und Regeln

Was ist ein Bruch?

Ein Bruch besteht aus einem Zähler und einem Nenner:
$ \frac{a}{b} $ mit $ b \neq 0 $.

Er beschreibt, wie viele Teile von einem Ganzen genommen werden.

Addieren von Brüchen

Brüche werden addiert, indem man sie auf einen gemeinsamen Nenner bringt:
$ \frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd} $.

Subtrahieren von Brüchen

Analog zur Addition:
$ \frac{a}{b} - \frac{c}{d} = \frac{ad - bc}{bd} $.

Multiplikation von Brüchen

Zähler mal Zähler, Nenner mal Nenner:
$ \frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd} $.

Division von Brüchen

Man multipliziert mit dem Kehrwert:
$ \frac{a}{b} : \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c} $.

Umwandlung in Dezimalzahlen

Jeder Bruch kann durch Division in eine Dezimalzahl umgewandelt werden:
$ \frac{a}{b} = a : b $.
